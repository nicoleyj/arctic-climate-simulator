# 🐻‍❄️ Arctic Ice Climate Simulator

An interactive browser-based simulator showing the effects of climate change on Arctic sea ice. Built as a digital prop for **"The Shrinking Ice"** — a full-body interactive installation for children aged 10–12.

## How to use

Open `index.html` in any browser and drag the slider:

- **❄️ Healthy Ice** — thick ice, aurora, happy polar bear
- **🌡️ Warming** — ice cracks, bear gets worried
- **🔥 Critical** — ice almost gone, bear is crying

Use the **❄️ and 🏭 buttons** in the bottom-right corner to play ambient wind or industrial sounds.

## Files

| File | Description |
|------|-------------|
| `index.html` | Main simulator (self-contained) |
| `WindSound.mp3` | Arctic wind ambient sound |
| `IndustrialSound.mp3` | Industrial noise ambient sound |

Keep all three files in the same folder.

## Tech

Vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.
