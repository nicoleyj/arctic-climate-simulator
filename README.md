# 🐻‍❄️ Arctic Ice Climate Simulator

An interactive browser-based slider showing the effects of climate change on Arctic sea ice. Built as a digital prop for **"The Shrinking Ice"** — a full-body interactive installation for children aged 10–12.

## How to use

Open `index.html` in any browser and drag the slider:

- **❄️ Healthy Ice** — thick ice, aurora, happy polar bear
- **🌡️ Warming** — ice cracks, bear gets worried
- **🔥 Critical** — ice almost gone, bear is crying

## Tech

Single HTML file. No frameworks, no dependencies.
